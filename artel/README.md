# Survivors ARTEL QA 지원

프로젝트 55에 등록한 TC 23개와 QA용 개발 빌드 지원입니다. 등록은 실제 QA 통과를 의미하지 않습니다.

- `cases-revised-2026-11-13.json`: 게임 상태·입력·기대 결과로 정리한 TC 23개
- `registration-revised-2026-11-13.json`: 재등록 ID 3164~3186과 관찰값. 모두 DRAFT이며 폴더가 없습니다.
- TC 3171: D 키를 놓으면 플레이어가 오른쪽 이동을 멈추는지 확인합니다.

## 치트와 동작

| 이름 | 기능 |
| --- | --- |
| `set_invincible(enabled)` | 현재 플레이어의 무적을 켜거나 끕니다. 새 플레이어에서는 꺼집니다. 개발 빌드에서만 피해·피격·사망 처리를 막습니다. |
| `set_gold(gold)` | 메뉴의 골드를 지정하고 기존 저장 API를 호출합니다. |
| `set_health(health)` | 살아 있는 플레이어의 체력을 1 이상, 최대 체력 이하로 준비합니다. |
| `set_xp_to_next_level(remainingXp)` | 레벨업까지 필요한 경험치를 준비합니다. 실제 경험치를 주워야 레벨업합니다. |
| `spawn_enemy_group(spawnSet)` | 현재 스테이지의 포위·밀집 스폰 세트를 실행합니다. 빈 이름은 가능한 세트를 반환합니다. |
| `kite_enemies(seconds)` | 기존 이동 경로로 적에게서 멀어집니다. 키보드를 건너뛰므로 입력 검증에는 사용하지 않습니다. |

피해·사망 TC에서는 무적을 꺼야 합니다. 함수 호출의 실제 동작은 아직 검증하지 않았습니다.

`SurvivorsQaState`는 화면 상태, 체력, 경험치, 골드, 선택 캐릭터·레벨 등의 관찰값을 제공합니다. 선택 캐릭터·레벨에는 변수 메타데이터가 있습니다. 서버에는 관찰값 설명 12개와 규칙 6개를 등록했습니다.

## 개발 빌드

Unity 2022.3.62f3에서 `SurvivorsQaBuild.Run`을 실행합니다. Addressables와 Windows 개발 빌드를 생성합니다. 빌드 스크립트는 별도 QA 프로젝트에서 실행하도록 작성되었으며 출력은 그 프로젝트의 형제 폴더 `qa-build`입니다. QA 빌드의 productName은 `Survivors Artel QA 55`이므로 일반 빌드의 저장과 분리됩니다.

SDK는 검증에 사용한 커밋으로 고정했습니다. `.artel/`의 로컬 빌드·로그·백업은 Git에서 제외합니다. 콘솔 승인과 실제 게임 입력·치트 호출 검증은 별도로 필요합니다.

## 반복 가능한 사전조건 준비

- `set_character_unlocked(character, unlocked)`: Assassin 또는 Mage의 해금 여부를 저장합니다. Mage 테스트는 false로 준비합니다.
- `reset_might_upgrade()`: 골드와 다른 강화를 유지하고 Might 단계만 0으로 저장합니다.

두 함수 모두 메뉴에서 호출하고 게임을 재시작해야 카드 표시와 런타임 강화 수치가 다시 초기화됩니다. 저장 성공 여부를 확인하며 기존 저장 전체를 삭제하지 않습니다. Test Run 160의 강화·캐릭터 시나리오 4개와 Test Run 161의 자유형 시나리오에 준비 방법을 반영했습니다.
